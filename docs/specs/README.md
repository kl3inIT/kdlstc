# Spec — mỗi lát cắt nguồn một tệp

Spec trả lời câu **"đơn vị này là gì?"** — sự việc riêng của một lát cắt: nguồn
ở đâu, hợp đồng dữ liệu ra sao, bảng nào, quy tắc nào.

Cơ chế dùng chung giữa nhiều lát cắt thì thuộc [../guidelines/](../guidelines/),
không thuộc đây. Khi phân vân, để trong spec: tách ra thành cơ chế chung sau
này dễ hơn là gỡ một sự việc riêng đã trót áp cho các lát cắt nó không hề chi phối.

| Lát cắt | Nguồn | Spec |
